Programa del sumador de 6 bits

Diseño de los semisumadores

Ecuaciones de suma (S) y acarreo (C) para el proyecto[cite: 7]:

Bit 0:

C0 = A0 · B0

S0 = A0 ⊕ B0

Bit 3:

C3 = A3C2 + B3C2 + A3B3

S3 = A3 ⊕ B3 ⊕ C2

Bit 1:

C1 = A1C0 + B1C0 + A1B1

S1 = A1 ⊕ B1 ⊕ C0

Bit 4:

C4 = A4C3 + B4C3 + A4B4

S4 = A4 ⊕ B4 ⊕ C3

Bit 2:

C2 = A2C1 + B2C1 + A2B2

S2 = A2 ⊕ B2 ⊕ C1

Bit 5 (Salida Final):

CS = A5C4 + B5C4 + A5B5

S5 = A5 ⊕ B5 ⊕ C4

Código VHDL

LIBRARY IEEE;
USE IEEE.STD_LOGIC_1164.ALL;
USE IEEE.STD_LOGIC_ARITH.ALL;
USE IEEE.STD_LOGIC_UNSIGNED.ALL;

ENTITY sumador_6bits IS
PORT (
    A0,A1,A2,A3,A4,A5 : IN STD_LOGIC; 
    B0,B1,B2,B3,B4,B5 : IN STD_LOGIC; 
    S0,S1,S2,S3,S4,S5,CS : OUT STD_LOGIC
);
END sumador_6bits;

ARCHITECTURE BEHAVIORAL OF sumador_6bits IS 
SIGNAL C0,C1,C2,C3,C4: STD_LOGIC;
BEGIN
    C0 <= (A0 AND B0);
    S0 <= A0 XOR B0;
    
    C1 <= ((A1 AND C0) OR (B1 AND C0) OR (A1 AND B1));
    S1 <= A1 XOR B1 XOR C0;
    
    C2 <= ((A2 AND C1) OR (B2 AND C1) OR (A2 AND B2));
    S2 <= A2 XOR B2 XOR C1;
    
    C3 <= ((A3 AND C2) OR (B3 AND C2) OR (A3 AND B3));
    S3 <= A3 XOR B3 XOR C2;
    
    C4 <= ((A4 AND C3) OR (B4 AND C3) OR (A4 AND B4));
    S4 <= A4 XOR B4 XOR C3;
    
    CS <= ((A5 AND C4) OR (B5 AND C4) OR (A5 AND B5));
    S5 <= A5 XOR B5 XOR C4;
END BEHAVIORAL;

Conexión a tarjeta MAX II (Configuración en Quartus)

1

Creamos un nuevo proyecto, elegimos la carpeta donde lo vamos a guardar y le ponemos un nombre relacionado con lo que estamos trabajando, para tenerlo bien identificado[cite: 7].

2

Seleccionamos la opción Empty project para crear un proyecto desde cero, sin archivos ni diseños previos. Esto nos permite agregar nuestro propio código y configurar el circuito del sumador de 6 bits[cite: 7].

3

Como no tenemos proyectos anteriores para agregar, dejamos esta parte vacía y simplemente damos clic en “Next” para continuar[cite: 7].

4

Ahora seleccionamos el tipo de tarjeta en la sección Device Family, eligiendo MAX II. Después, en Pin count, seleccionamos la opción de 100 pines. Por último, en Available devices, buscamos el modelo de la tarjeta que aparece impreso en la placa. Es importante revisar que todos los números y letras coincidan exactamente para evitar errores[cite: 7].

5

Seleccionamos el lenguaje de programación que vamos a utilizar para el proyecto, en este caso, VHDL. Después, continuamos con el siguiente paso de la configuración[cite: 7].

6

Al terminar este proceso, aparecerá una pantalla con un resumen de todas las opciones que seleccionamos durante la configuración del proyecto. Aquí podemos revisar que todos los datos sean correctos antes de continuar[cite: 7].

7

Una vez terminado el proceso, nos dirigimos a la opción New File y seleccionamos VHDL File, donde vamos a escribir el código de nuestro sumador de 6 bits. Y empiezas con la codificación del mismo[cite: 7].
